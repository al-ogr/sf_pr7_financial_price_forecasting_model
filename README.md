### Описание проекта
В рамках проекта по разработке автоматической торговой системы требуется получение прогноза направления движения финансового актива (фьючерс на золото), а также предполагаемых значений коридора движения цены, а именно максимума и минимума за период максимальной продолжительности сделки в рамках дейтрейдинга.

:arrow_up:[к оглавлению](README.md#Оглавление)


### Задачи кейса   
В рамках данного проекта необходимо сформировать модели прогнозирования коридора цен фьючерса на золото на базе новостной ленты канала Telegram [MarketTwits](https://t.me/markettwits) и показателей технических индикаторов. В ходе работы обучается четыре модели, прогнозирующие за установленный период:
- максимальную цену;
- минимальную цену;
- основное направление движения цены актива: рост/падение (относительно цены закрытия).

:arrow_up:[к оглавлению](README.md#Оглавление)


### Краткая информация о данных
Используемые в проекте данные (как исходные, так и промежуточные) доступны для обзора и скачивания на платформе Kaggle [Financial quotes for gold](https://www.kaggle.com/datasets/alexogr/financial-quotes-for-gold/data).

Датасет включает в себя:
- исторические данные по золоту (GOLD), доступны на странице "Актуальных архивов исторических данных (котировок)" (https://daytradingschool.ru/trejderu/skachat-kotirovki-istoricheskie-dannye-po-fyuchersam/);
- новостную ленту Telegram-канала MarketTwits (https://t.me/markettwits).

### Результаты  
В ходе выполнения задач кейса была произведена загрузка сообщений новостного канала (файл [MsgDownload.ipynb](https://github.com/al-ogr/sf_pr7_financial_price_forecasting_model/blob/main/MsgDownload.ipynb))*, сформировано четыре модели, позволяющих построить рекомендательную систему (файл [FPFM.ipynb](https://github.com/al-ogr/sf_pr7_financial_price_forecasting_model/blob/main/FPFM.ipynb)).  
Так как данный этап работы является стартовым и отсутствуют сведения о торговой стратегии на базе сигналов, получаемых от моделей в комплексе, в том числе и о стратегии риск-менеджмента, оценка моделей производилась с использованием стандартных метрик. С учетом этого факта при построении торговой стратегии необходимо учитывать особенности полученных моделей.  
Итоговые модели обучены на полных данных и сохранены в файлы, как и необходимые кодировщики и вспомогательные данные. Функции получения прогноза с учетом пред- и постобработки данных собраны в файле [getPredict.py](https://github.com/al-ogr/sf_pr7_financial_price_forecasting_model/blob/main/getPredict.py).
Для получения прогноза с использованием моделей производится инициализация класса predictModels и вызывается функция getPredict:  
 ``` 
 # Инициализация класса
 gp = predictModels()
 # Получение прогноза
 pred_to_up, pred_to_down, pred_high, pred_low, close_x = gp.getPredict(df_test, df_test_msgs)
 ```
     
***df_test*** - pd.DataFrame, содержащий данные минутных свечей с колонками:
- 'dt' (datetime64[ns]) - время формирования свечи;
- 'open' (float) - цена открытия;
- 'high' (float) - максимальная цена;
- 'low' (float) - минимальная цена;
- 'close' (float) - цена закрытия;
- 'volume' (float) - объем торгов.
Количество свечей должно обеспечивать рассчет технических индикаторов в масштабе 15 минут (при текущих значениях индикаторов не менее 405 объектов)

***df_msgs*** - pd.DataFrame с индексом типа DatetimeIndex (время публикации новости) и колонкой 'message' (object) - текст новостного сообщения.  
Количество записей должно обеспечить две значимые новости (параметры очистки приведены в [FPFM.ipynb](https://github.com/al-ogr/sf_pr7_financial_price_forecasting_model/blob/main/FPFM.ipynb) в разделе **"Предварительная подготовка данных"-"Сообщения новостного канала"**) (рекомендую порядка 10-30 сообщений).
Возвращаемые значения:
- pred_to_up (bool) - основной тренд восходящий;
- pred_to_down (bool) - основной тренд нисходящий;
- pred_high (float) - максимальная прогнозируемая цена;
- pred_low (float) - минимальная прогнозируемая цена;
- close_x (float) - цена закрытия на момент начала построения прогноза.
